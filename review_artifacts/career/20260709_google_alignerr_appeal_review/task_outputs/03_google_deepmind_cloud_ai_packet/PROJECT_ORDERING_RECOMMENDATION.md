# Project Ordering Recommendation

## For Google Cloud AI / DeepMind-Style Review

1. **VisualBasilisk** - lead source artifact: public, tested, scoped, source-first bridge.
2. **Basilisk jet benchmark visualization** - strongest public page showing scientific evidence curation and claim boundaries.
3. **VisualOpenFOAM / OpenFOAM KH proxy** - CFD/numerical-method review and topology/fidelity audit.
4. **DualSPHysics SPH visualization family** - solver-output postprocessing and conservative public visualization.
5. **ideal-momentum-jet-explorer** - model explanation and educational scientific computing.
6. **Internal-nozzle Basilisk docs** - mention only as internal/review evidence; not public lead.

## Rationale

Lead with artifacts that are public, scoped, and not dependent on private raw outputs. Put VisualBasilisk first because it is source-first and maps cleanly to research engineering and responsible AI tooling. Put Basilisk/OpenFOAM/DualSPHysics next as domain evidence. Put model explorers and private/internal tracks as supporting proof.

## Avoid

- Leading with raw videos or stack-validation folders.
- Leading with internal-nozzle results, because the public status is not public-ready scientific validation.
- Presenting the page as a direct job application to Google or DeepMind.
