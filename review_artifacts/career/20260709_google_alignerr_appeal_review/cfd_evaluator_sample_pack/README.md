# CFD Evaluator Sample Packet

This packet contains self-authored CFD and scientific-visualization evaluation examples for public-safe review. It is intended to show evaluation style, not to reproduce any private assessment, platform prompt, or employer-specific material.

Recommended inspection order:

1. `PUBLIC_USE_BOUNDARY.md`
2. `CFD_EVALUATOR_SAMPLE_PACK.md`
3. `SAMPLE_MANIFEST.json`

The examples focus on common review failures:

- confusing connected VOF waviness with breakup;
- rendering unavailable pressure fields;
- mixing pressure-driven internal-nozzle evidence with imposed-inlet comparisons;
- claiming convergence from misaligned station/time data;
- treating single-phase or reduced-dimensional visual demos as validation.

Allowed use: review the evaluator style, rubric categories, safe corrected wording, and evidence requirements.

Not allowed: treat these samples as answer keys, live-platform assessment material, proof of employment, proof of acceptance by any platform, validation evidence, production-CFD evidence, or atomisation-prediction evidence.
