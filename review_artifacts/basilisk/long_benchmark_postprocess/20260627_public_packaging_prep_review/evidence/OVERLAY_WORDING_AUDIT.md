# Overlay Wording Audit

## Acceptable internal wording already present

- `internal review`
- `not validation`
- `public_ready=false`
- `2:1 rectangular top-hat imposed-inlet comparison`
- pressure-blocked/no-pressure naming in field media.

## Wording to avoid in any future public draft overlay

- showcase
- portfolio-ready
- recruiter
- client-facing
- final
- production
- validation
- true atomisation
- pressure-atomized-nozzle validation
- internal-nozzle flow for the rectangular route
- Poiseuille for the selected rectangular route

## Preferred future public-facing wording

- `technical sample`
- `research workflow sample`
- `Basilisk-to-Blender pipeline sample`
- `two-phase VOF benchmark`
- `solver-derived facets`
- `imposed-inlet rectangular comparison`
- `not validation`

## Result

Existing V3.1 overlay wording is safe for internal review but too internal/process-heavy for final public packaging. Do not publish these overlays as final public media without a separate human-approved public copy pass.
