# DualSPHysics 08_ImpingingJet Composite Showcase

Date: 2026-06-12

## Case Classification

This showcase uses the official DualSPHysics v5.4 example:

`examples/inletoutlet/08_ImpingingJet`

The case is classified as a 2D single-phase inlet/outlet impinging-jet demo. It
is not a 3D atomized jet, liquid-gas spray breakup, statistically stationary
spray simulation, or validation against experiment.

## Surface Reconstruction

Surface reconstruction succeeded using the official `IsoSurface_linux64`
postprocessor on existing BI4 data. The final hero view uses a straight-on
front-orthographic reconstructed-surface render to preserve the 2D nature of
the case.

No oblique camera view is used in the final deliverables.

## Scalar Fields

The existing `particles/PartFluid_*.vtk` files contain:

- `Idp`
- `Vel`
- `Rhop`

They do not contain `Press`.

The reconstructed `Surface_*.vtk` files generated by `IsoSurface_linux64`
contain:

- `Vel`
- `Rhop`
- `Press`

The analysis video uses velocity magnitude and pressure from those
postprocessed surface VTK files. Pressure is therefore a real exported
postprocessing field from existing BI4 data, not a fabricated overlay.

## Difference From ShapesInlet3D

The ShapesInlet3D showcase is a separate official inlet example and was not
modified for this package. This ImpingingJet package focuses on the official
2D CaseJet2D impinging-jet example and uses a front-on reconstructed-surface
presentation plus scalar analysis sections.

## Difference From Atomized-Jet Target

This case remains useful as an official inlet/outlet visualization candidate,
but it does not model liquid-gas atomization, droplet breakup, or statistically
stationary spray physics. A dedicated multiphase liquid-gas route or bounded
Basilisk atomisation route is still required for the atomized-jet research
target.
