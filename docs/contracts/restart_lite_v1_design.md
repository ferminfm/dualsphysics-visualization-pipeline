## State inventory

- Native-dumped state: adaptive tree topology, simulation time and iteration,
  domain origin and size, named cell-centered fields including volume fraction,
  centered velocity, pressure, embedded cell fractions, and three named scalar
  snapshots of the projected face velocity. The target clears the default
  pressure `nodump` policy before its restore decision so pressure is present in
  the native field list used by both dump and restore.
- Deterministic static state: domain, nozzle dimensions, physical properties,
  tolerances, stopping targets, and boundary conditions are loaded from the
  command line before the restore decision.
- Reconstructed state: vertex geometry, embedded cell/face fractions and
  face-centered material properties are regenerated after restore. The saved
  projected face-velocity snapshots are copied back to the face vector before
  the first resumed stability/advection step; other solver auxiliaries are
  regenerated by normal Basilisk events.
- Minimal non-field sidecar state: version, dump iteration/time, the next
  timestep and the application checkpoint counter. It contains no mesh, field
  arrays, hashes, paths, or custom restart records. Native Basilisk dump/restore
  remains the sole owner of mesh and physical-field state.
- Derived application state: output sequence numbers remain derived from
  restored `i`; the gate phase and bounded levels are explicit arguments. No
  random source is used.

## Event and checkpoint contract

Configuration is loaded first. The initialization event establishes the native
pressure dump policy, attempts native `restore()` and performs fresh field
initialization only if restore returns false. Geometry and material properties
are rebuilt after either path. A checkpoint event declared in the `i++,last`
group after the solver definitions snapshots projected face velocity and writes
the native dump at the documented end-of-step point. A bounded event trace
confirmed that projection and diagnostics precede the checkpoint. Gate 4 uses
an external standard-library wrapper to preserve generations and record
resources without changing the native file format.

## Validation ladder

Gate 1 proved separate-process native restore and one resumed step on the actual
bounded internal-nozzle target. Gate 2 proved exact immediate checkpoint-boundary
continuity. Gate 3 proved exact short uninterrupted-versus-split continuity
under the pinned tolerances after correcting native pressure-list timing and
preserving projected face state. Gate 4 completed three logical segments with
exact boundaries at iterations 4, 8 and 12, base level 5/maximum level 6, peak
RSS below 111 MiB per restored segment and about 116 MiB overall. No produced
binary is treated as a production solver, and no L7/L8 claim is made.
