# Basilisk Internal-Nozzle Claim Boundary

This repository capture is allowed to describe a pressure-driven Basilisk
internal-nozzle prototype and its source/provenance. It is not allowed to
promote the batch as validation, public-ready spray evidence, or a predictive
model result.

## Allowed Description

- pressure-driven 2:1 rectangular internal-nozzle calibration;
- no imposed uniform exit velocity;
- embedded no-slip internal-wall harness;
- stable connected two-phase internal-nozzle prototype;
- reproducible connected-jet handoff case;
- exploratory geometry metrics for internal reduced-model interface testing;
- quarter-symmetry scout results that require full-domain confirmation for
  morphology-sensitive claims.

## Prohibited Description

Do not describe this batch as:

- validated atomisation or atomization;
- true breakup;
- pressure-atomized-nozzle validation;
- production CFD;
- stationary spray data;
- experimental agreement;
- public-ready showcase evidence;
- final predictive modeling;
- fit-ready reduced-model calibration data.

## Morphology Interpretation

A connected jet or connected waviness is not breakup. One-cell debris,
pre-exit components, mirror copies, and projection artifacts are not detached
liquid evidence.

The two-phase prototype and robustness window both produced connected-jet
classifications. The conservative conclusion is therefore:

`stable pressure-driven connected-jet prototype; no internal-nozzle breakup candidate`

## Geometry Handoff Boundary

The geometry handoff used upstream metric repackaging, not raw VOF field
extraction. Every downstream model-interface use should preserve these limits:

- not stationary;
- not for model fit;
- usable only for shape-trend and overlay interface checks unless a separate
  raw-field export/convergence task is completed.
