# Basilisk Internal-Nozzle Batch Summary

This note captures the source/docs-only public repository record for the
2026-06-20 Basilisk internal-nozzle batch. It is an internal review candidate,
not a public-ready spray or atomisation result.

The batch preserved a pressure-driven interpretation throughout:

- no imposed uniform exit velocity at the nozzle exit;
- no-slip embedded internal walls;
- 2:1 rectangular outlet geometry;
- stable connected two-phase jet behavior;
- no credible internal-nozzle breakup proxy;
- quarter symmetry useful only as a scout;
- exploratory geometry/model overlays only.
