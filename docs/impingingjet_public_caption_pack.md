Date: 2026-06-12

## YouTube Title

Official DualSPHysics 2D Impinging-Jet Visualization Demo

## YouTube Short Description

Front-on reconstructed-surface and scalar-analysis showcase from the official
DualSPHysics `08_ImpingingJet` / `CaseJet2D` example. This is a 2D
single-phase inlet/outlet visualization demo, not atomization, not liquid-gas
spray breakup, and not validation.

Generated from an existing official DualSPHysics run using IsoSurface,
particle VTK output, headless Blender, and ffmpeg. Pressure was absent from the
original `PartFluid_*.vtk` files but available from IsoSurface postprocessing
of the existing BI4 data.

## GitHub/Vercel Card Title

DualSPHysics 2D Impinging-Jet Showcase

## Project Description

This showcase packages the official DualSPHysics `08_ImpingingJet` example as a
public-facing scientific visualization: a front-on reconstructed-surface hero
clip, particle and impact-region views, and scalar postprocessing panels for
velocity magnitude and reconstructed-surface pressure. The workflow uses
existing solver outputs and keeps raw BI4/VTK data, frames, logs, and MP4s
outside Git.

## Caveat Line

Visualization demo -- 2D single-phase official DualSPHysics example; not
atomization, not liquid-gas spray breakup, not production CFD, and not
experimental validation.
